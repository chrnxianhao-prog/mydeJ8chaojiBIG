以前 vs 那一次

你已经会说「昨天做了」：llegó、compré、cerré。
可是中文说「以前我每天卖衣服」，西语的动词变得不一样：vendía，不是 vendí。

今天就分这两格：以前常常做，和某一次做完了。

声音　Dalia 是 Edge 浏览器「大声朗读」的墨西哥女声，电脑上用 Edge 打开才有；没有时自动用 Kokoro。

以前常常做，还是那一次做完

以前、总是、每天、每周二（反复做）
　→　-ar 动词加 -aba，-er / -ir 动词加 -ía　llegaba、vendía
昨天、有一天、那个周二（一次做完）
　→　-ó / -é / -í　llegó、llegué、vendí

看句子里的时间词：antes、siempre、cada… 是「常常」；ayer、un día、el martes 是「那一次」。

每组三句都点，听完再翻中文。llev- 和 lleg- 也单独放了一组，上次听写你把 llevó 听成了 llegó。
