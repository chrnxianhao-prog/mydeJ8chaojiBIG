Usted 命令式

跟客户、供应商、医生、办事窗口说话全都用 usted。这几句你每天在街上被人说， 先听得出来，再谈开口。

练习那页答案能翻、不计分；测试那页盖住答案，交卷算分。

街上天天听到的

先听，想意思，再翻答案。别看着字听。

一条规则，不规则动词也管用

从「我」的现在式出发，砍掉 -o，-ar 加 e、-er/-ir 加 a。
紫色是「我在做」，绿色是「请您做」。先听紫的，再听绿的，听差别在哪儿。

练熟了再切到测试那页。那边答案是盖住的，交卷才出分。

练习那页过完了再做。一边翻答案一边考，测出来的是抄写速度。

第一节 · 听辨（12 题）

听一个词，判断是「我在做」还是「请您做」。 差别只在最后一个元音：-o 是我，-a / -e 是您。

第二节 · 写出命令形（6 题）

给你原形，写 usted 的命令形。走三步：yo 现在式 → 砍掉 o → 换尾巴。

第三节 · 填进句子（4 题）

括号里是原形，把命令形填进去。句首要大写。

成绩自动传回来，不用你抄。
