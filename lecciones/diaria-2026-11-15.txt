# Lección diaria — Confirmar la entrega con el proveedor
// 语音版每日练习 · 2026-11-15 · A2 · 仓库场景
// 重点：时间词定三时态 — Mañana + 将来 -ré / Antes + 以前常 -aba·-ía / Ayer + 一次 -é·-ó（第五轮，换跟供应商确认补货、跟司机约卸货时间的场景）
// 复习：le 间接宾语（le confirmaré / le escribí）、faltaron 复数、devolver 过去式、条件式委婉请求 podría
// 新词：confirmar, la entrega, reponer, el mismo día
// 节奏：西语正常速 → 停 0.5 秒 → 西语慢速 → 跟读时间 → 中文释义 → 停 1.5 秒
// 注意：小节标题（# 开头的行）会被西语音色念出来，所以标题只写西语，中文说明写在 // 批注里

# Mañana
// 将来时 -ré：明天要做的事
Mañana le confirmaré al proveedor la hora de entrega. = 明天我会跟供应商确认送货时间。
Mañana le enviaré al proveedor la lista de las cajas que faltan. = 明天我会把缺货清单发给供应商。
Mañana repondremos las cajas que faltaron ayer. = 明天我们会把昨天少的箱子补上。

# Antes
// 以前常 -aba / -ía：过去的习惯
Antes el proveedor siempre confirmaba la entrega por teléfono. = 以前供应商总打电话确认送货。
Antes yo llamaba al conductor antes de las ocho. = 以前我八点前就给司机打电话。
Antes reponíamos las cajas el mismo día. = 以前我们当天就把箱子补上。

# Ayer
// 一次 -é / -ó：昨天做完的事
Ayer le escribí al proveedor y me confirmó la entrega. = 昨天我给供应商写了消息，他确认了送货。
Ayer el conductor llegó tarde y no avisó. = 昨天司机来晚了，也没提前说。
Ayer devolvimos dos cajas rotas al proveedor. = 昨天我们把两个破箱子退给了供应商。

# Repaso
// 条件式 podría：委婉请求
¿Me podría confirmar la hora, por favor? = 您能帮我确认一下时间吗？
