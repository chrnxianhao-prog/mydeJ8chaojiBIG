# Lección diaria — Inventario con el montacargas
// 语音版每日练习 · 2026-11-11 · A2 · 仓库场景
// 重点：时间词定三时态 — Mañana + 将来 -ré / Antes + 以前常 -aba·-ía / Ayer + 一次 -é·-ó
// 复习：le 间接宾语（le pediré / le di）、falta/faltan 单复数、traer 过去式 trajo、subir
// 节奏：西语正常速 → 停 0.5 秒 → 西语慢速 → 跟读时间 → 中文释义 → 停 1.5 秒
// 注意：小节标题（# 开头的行）会被西语音色念出来，所以标题只写西语，中文说明写在 // 批注里

# Mañana
// 将来时 -ré：明天要做的事
Mañana contaremos todas las cajas de la estantería tres. = 明天我们会数完三号货架上的所有箱子。
Mañana le pediré la lista nueva a mi compañera Ana. = 明天我会向同事安娜要一份新清单。
Mañana subiré las cajas pesadas a la estantería alta. = 明天我会把重箱子搬到高货架上。

# Antes
// 以前常 -aba / -ía：过去的习惯
Antes hacíamos el inventario con papel y lápiz. = 以前我们用纸和笔做盘点。
Antes el montacargas siempre estaba en la entrada. = 以前叉车总停在门口。
Antes yo llegaba a las siete y abría la bodega. = 以前我七点到，开仓库门。

# Ayer
// 一次 -é / -ó：昨天做完的事
Ayer conté doscientas cajas y encontré cinco dañadas. = 昨天我数了二百个箱子，发现五个坏的。
Ayer el conductor me trajo las cajas tarde. = 昨天司机很晚才把箱子送来。
Ayer le di la lista al jefe. = 昨天我把清单给了老板。

# Repaso
// faltan 复数 + está 状态
Ayer faltaban dos cajas en el inventario. = 昨天盘点时少了两个箱子。
